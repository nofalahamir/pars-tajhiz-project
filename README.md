### 🔧 **ویژگی‌های فنی**

#### 1. **اعتبارسنجی فرم**
```javascript
// الگوهای اعتبارسنجی فارسی
name: /^[\u0600-\u06FF\s]{3,50}$/
email: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
phone: /^[\d\s\-\(\)]{10,15}$/
message: /^[\u0600-\u06FF\s\d\.,!?]{10,500}$/
```

### 🎨 **سفارشی‌سازی**

#### **رنگ‌های دارک مود**
```css
:root {
    --primary-color: #f39c12;    /* رنگ اصلی */
    --dark-bg: #1A1A1A;         /* پس‌زمینه تیره */
    --medium-bg: #2B2B2B;       /* پس‌زمینه متوسط */
    --text-color: #EAEAEA;      /* رنگ متن */
}
```

#### **رنگ‌های لایت مود**
```css
[data-theme="light"] {
    --bg-color: #ffffff;        /* پس‌زمینه روشن */
    --bg-medium: #f8f9fa;       /* پس‌زمینه متوسط */
    --text-primary: #2c3e50;    /* رنگ متن اصلی */
    --text-secondary: #6c757d;  /* رنگ متن فرعی */
}
```
